# Subham Patro — Portfolio

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser. No build tools are required.
3. For best testing, use VS Code + Live Server.

## Before publishing
- Replace `subhampatro@example.com` in `index.html` with your real email (including the `PORTFOLIO_EMAIL` value).
- Add `assets/profile.jpg` (your photo). It appears in both the Home section and the About Me section.
- Add `assets/Subham-Patro-Resume.pdf` (your resume).
- Replace all generic GitHub, LinkedIn, Instagram and Telegram links with your actual profile URLs.
- Replace project repository links with your own repositories.
- Verify project claims, experience, education year, grades and project count; remove anything that does not accurately describe your background.
- Add real employment/internship details if applicable.

## Contact form
The contact form uses a `mailto:` link. It opens the visitor's email app and prepares an email; it does not deliver messages through a server. For a server-backed form, connect a form service or build a backend endpoint.

## Hosting
You can host this static website on GitHub Pages, Netlify or Vercel. Keep `index.html` and the `assets` folder together.
